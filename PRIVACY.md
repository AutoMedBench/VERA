# Privacy and release boundary

This is a new source-only export with new Git history and a neutral commit
identity. It does not import the original repository's objects or authors.

Excluded: credentials and signing keys, environment/auth files, cluster
launch configuration, account/profile data, operator paths, run reports,
transcripts, task records, private/evaluator references, datasets, images,
model weights, checkpoints, caches, deployment receipts and original Git history.
Source-level operator identifiers and infrastructure references were replaced
with generic examples. External assets must be supplied separately by their
authorized operator. Placeholder paths are not an installation configuration.

The privacy audit covers the committed source bytes and new commit metadata.
Automated scanning is not an absolute guarantee of anonymity. GitHub still
knows the authenticated account and displays repository ownership to people
who can access the repository. Keep the repository private unless the owner
explicitly approves a separate public-release review.

Skill provenance metadata was privacy-filtered and its commitments regenerated
for these exported bytes. These are export commitments, not historical training
receipts. Canonical skill IDs, stage grants, tool schemas and license restrictions
remain intact. Original evidence and sources are not modified by this export.
