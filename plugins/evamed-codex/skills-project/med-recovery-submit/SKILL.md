---
name: med-recovery-submit
description: Recover a bounded medical-research run after tool or context failure and complete validation and submission within remaining limits.
---

Recall the task contract, evidence registry, artifact references, failed
attempts, and next action. Do not repeat a failed action without changing the
cause. Reserve enough time to validate required files and submit. Classify a
failure as infrastructure only through authenticated benchmark evidence;
malformed model calls and invalid outputs remain model failures.
