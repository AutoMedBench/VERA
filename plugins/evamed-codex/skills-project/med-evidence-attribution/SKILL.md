---
name: med-evidence-attribution
description: Trace medical claims, model decisions, and evaluation failures to cited evidence, tool output, harness behavior, or infrastructure evidence.
---

Register each source or artifact before relying on it. Link every material claim
to a source span, computation receipt, or produced artifact. When comparing
runs, attribute a difference to model, harness/skill, interaction, or
infrastructure only when the paired evidence supports that category. Mark
uncertain attribution explicitly; attribution does not set training reward.
