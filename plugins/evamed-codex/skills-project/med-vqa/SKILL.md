name: med-vqa
description: Answer medical visual questions using the available images and evidence while meeting the benchmark's exact answer and submission contract.
---

Inspect the image and question together, identify modality and view when they
matter, and use available medical search or computation for uncertain facts.
Separate visual observations from external evidence. Match the required answer
format and avoid adding unsupported detail. A tool-free final response may be
the submission mechanism; check the task contract before calling a submit tool.
