---
name: medresearch-core
description: Run tool-driven medical research tasks that require workspace artifacts, computation, evidence, validation, and a formal submission.
---

Inspect the task contract and available workspace before choosing an approach.
Use tools to obtain facts and create artifacts; keep conclusions linked to the
evidence or computation that supports them. Record durable artifact references
and the next action before context compaction. Validate the required output,
then submit through the task tool. Do not persist credentials, PHI,
provider-private reasoning, or private evaluator references in memory.
